# Chapter 1: Introduction and Motivation

## 1.1 Research Background and Motivation
Numerical modeling of complex coastal and marine natural hazards, such as landslide-generated tsunamis and localized scour processes around coastal infrastructure, constitutes a foundational pillar in coastal engineering and disaster mitigation. Over the past several decades, specialized high-performance computing (HPC) software platforms—specifically legacy Fortran-based computational fluid dynamics (CFD) codes such as the Truchas/Splash3D platform—have contributed significantly to the understanding of non-linear free-surface dynamics, multi-phase flows, and fluid-structure interactions. These specialized solvers retain high scientific value due to their tailored physical formulations, such as dual-viscosity representations and bed-evolution modules, which are often absent or overly simplified in generalized commercial packages.

Despite their established numerical accuracy, long-standing legacy HPC packages face severe operational and infrastructure bottlenecks that hinder their sustainability in modern scientific research. Historically developed for bare-metal UNIX or early Linux server environments, these platforms rely heavily on obsolete compilation standards, static memory allocation logic, and deprecated third-party libraries for parallel communication and linear system solving. As underlying server hardware and host operating systems inevitably advance, maintaining these legacy computational environments requires locking server configurations to outdated software versions. Consequently, this architectural rigidity leads to severe accessibility issues, where software execution becomes highly restricted to isolated, legacy hardware within specific research groups. Over decades of uncoordinated development, arbitrary code modifications without strict version control further result in fragmented code forks, memory allocation errors, and compromised numerical reproducibility.

In the contemporary CFD ecosystem, general-purpose commercial software suites (e.g., ANSYS FLUENT, FLOW-3D) and dominant open-source platforms (e.g., OpenFOAM) have advanced rapidly, offering extensive active community support, dynamic GPU acceleration, and emerging AI-assisted execution pipelines. This stark contrast raises a fundamental architectural question regarding software sustainability: why modernize a specialized legacy CFD platform rather than completely transitioning to an established community package such as OpenFOAM? The rationale for modernizing and preserving the specialized Truchas platform rests on two critical scientific imperatives: domain-specific numerical assets and academic continuity. Over decades of specialized development, the Truchas/Splash3D platform has been embedded with highly customized physical formulations—specifically tailored for non-Newtonian dual-viscosity flows, dynamic bed-evolution (DBM) interfaces, and fluid-structure interactions—that are uniquely tuned for coastal and hydraulic disaster scenarios. Completely migrating these specialized physical modules into general-purpose frameworks like OpenFOAM would require extensive re-implementation and re-validation, incurring immense time costs and creating an academic fracture. Furthermore, abandoning legacy software entirely contributes to the "reproducibility crisis" in computational science, rendering decades of historical simulation data and lab publication baselines unrepeatable. Therefore, modernizing the Truchas platform is not a rejection of modern CFD frameworks like OpenFOAM, but rather a vital strategy to salvage specialized domain knowledge, bridge legacy Fortran physics with modern software infrastructure, and ensure long-term research continuity.

Furthermore, a significant workflow friction exists between classical HPC platforms and modern scientific computing environments. In practical research workflows, pre-processing tasks (such as mesh generation and parameter configuration) and post-processing visualization are increasingly performed on workstation computers running modern desktop operating systems, predominantly Microsoft Windows. Conversely, legacy CFD solvers remain strictly tied to Linux-native POSIX environments and X11 graphical rendering pipelines. Traditional attempts to bridge this gap—such as relying on full-system virtual machines (e.g., VMware or VirtualBox)—introduce substantial performance overheads, particularly in CPU scheduling and memory bandwidth, rendering them unviable for large-scale, parallel 3D hydrodynamic simulations. Direct native Windows compilation is similarly unfeasible due to deep dependencies on POSIX-compliant system calls and Linux-native parallel frameworks, which suffer from severe thread-scheduling degradation under non-native runtime environments.

The recent emergence of lightweight virtualization technologies, specifically Windows Subsystem for Linux 2 (WSL2) integrated with Linux Containers (LXD), presents a promising paradigm shift to resolve this historical dilemma. WSL2 provides a genuine Linux kernel running alongside the host operating system via a lightweight hypervisor, achieving native-like I/O throughput and low-latency system calls. When coupled with system containers such as LXD, this modern virtualization architecture enables the construction of highly isolated, fully reproducible, and portable Linux execution environments directly within desktop host systems. Furthermore, this modern architecture establishes a seamless bridge to emerging Python-based automation pipelines and Artificial Intelligence (AI) agent frameworks, which are fundamentally incompatible with legacy bare-metal setups. Therefore, modernizing the Truchas CFD platform through containerization represents a critical step toward preserving specialized hydrodynamic legacy software while elevating its computational reproducibility, execution efficiency, and accessibility.

## 1.2 Problem Statement and Research Scope
While the rationale for preserving and modernizing the Truchas/Splash3D platform has been established in contrast to adopting generalized frameworks like OpenFOAM, transitioning this specialized legacy code into a sustainable, future-proof computational environment exposes a series of deeply interconnected scientific, computational, and software engineering challenges. Throughout years of hands-on simulation practice—ranging from macro-scale tsunami propagation to micro-scale structural scour—the Truchas platform has repeatedly demonstrated superior numerical precision in resolving highly complex free-surface dynamics and fluid-bed interfaces. However, as grid resolutions increase to capture intricate three-dimensional flow features and fluid-structure-soil interactions, severe intrinsic limitations within the legacy computational architecture have become manifest, threatening the long-term survival of this valuable hydrodynamic asset.

The primary operational bottleneck stems from an acute computational execution barrier coupled with a critical fracture in academic continuity. Historically, executing parallel Truchas simulations required dedicated, bare-metal Linux server accounts managed locally within the research laboratory. While this centralized paradigm sufficed in earlier decades, it created a severe ecosystem isolation. As alumni graduated and transitioned to industry or external research institutions, they routinely abandoned Truchas in favor of OpenFOAM or commercial suites, not due to a lack of physical accuracy in Truchas, but solely because its rigid, outdated deployment dependencies rendered it virtually impossible to install or operate outside the lab's original server environment. Attempting to run legacy Truchas via full-system virtual machines (e.g., VMware or VirtualBox) on modern personal workstations yields abysmal computational efficiency—particularly in CPU thread scheduling and memory bandwidth under high grid densities—making large-scale 3D hydrodynamic research unviable. Consequently, if the underlying legacy servers decommission or if the software environment is not fundamentally modernizing before institutional personnel transitions occur, this specialized CFD platform, uniquely tailored for Earth science and coastal engineering applications, faces permanent obsolescence and total knowledge loss.

This crisis of computational software sustainability is further exacerbated by the rapid revolution in high-performance computing, particularly GPU acceleration and Artificial Intelligence (AI) workflows. While contemporary CFD platforms dynamically evolve to integrate parallel GPU solvers and LLM-driven simulation steering, legacy Truchas remains frozen in early-2000s Fortran paradigms, characterized by non-standardized memory management, hardcoded execution paths, and brittle parallel dependencies. In multi-phase hydrodynamic applications—such as the landslide-generated tsunami at Guishan Island and dynamic local scour around the multi-pier foundation of the Guandu Bridge—capturing multi-scale physical phenomena requires both absolute numerical stability and modern execution agility. To bridge this vast technological divide, the legacy codebase must undergo systematic modular refactoring to eliminate silent memory errors, while being encapsulated within a modern virtualization layer that can bridge classical Fortran physics with modern Python-based AI automation frameworks without sacrificing parallel scaling throughput.

Accordingly, the scope of this dissertation is articulated through a progressive multi-stage strategy. First, it establishes the physical fidelity, numerical stability, and multi-scale applicability of the Truchas platform by applying it to two highly challenging coastal and hydraulic engineering benchmarks: the macro-scale landslide-generated tsunami wave dynamics at Guishan Island, and the micro-scale localized bed-scour evolution around the multi-pier foundation of the Guandu Bridge. Second, it presents the architectural modernizing of the execution environment by deploying a highly portable, containerized infrastructure using Windows Subsystem for Linux 2 (WSL2) and Linux Containers (LXD), integrated with an LLM-driven supervisory agent framework for automated input validation, run-time monitoring, and diagnostic error handling. Third, using the Guishan Island landslide tsunami scenario as a primary physical benchmark, the dissertation executes a rigorous comparative performance analysis between the modern WSL2/LXD containerized setup and the legacy bare-metal server environment, quantitatively demonstrating that the modernized framework achieves equivalent numerical precision while vastly superior operational convenience, seamless Python/AI workflow extensibility, and highly competitive computational efficiency.

## 1.3 Research Objectives
The principal objective of this doctoral dissertation is to establish a modern, portable, and automated computational framework for the specialized Truchas CFD simulation suite, restoring its accessibility and long-term sustainability while validating its physical fidelity and numerical performance across multi-scale coastal hazard modeling. To achieve this primary goal, the specific research objectives are formulated as follows:

First, to rigorously evaluate and demonstrate the physical fidelity, numerical conservation, and multi-scale applicability of the Truchas CFD suite in complex coastal engineering challenges, specifically focusing on macro-scale landslide-generated tsunami dynamics at Guishan Island and micro-scale localized bed-scour evolution around the complex pier foundation of the Guandu Bridge.

Second, to design and deploy a lightweight, highly portable, containerized execution environment for the Truchas platform utilizing Windows Subsystem for Linux 2 (WSL2) and Linux Containers (LXD), ensuring complete POSIX compliance, seamless multi-threaded parallel execution, and cross-platform reproducibility directly within modern desktop operating systems.

Third, to design and construct an intelligent, Python-driven workflow automation supervisor powered by Large Language Model (LLM) agents, enabling automated input parameter verification, real-time simulation execution monitoring, diagnostic error detection, and streamlined data extraction without manual intervention.

Fourth, to execute a quantitative comparative benchmark between the modernized WSL2/LXD containerized framework and the legacy bare-metal server environment using the Guishan Island landslide tsunami scenario, evaluating numerical output reproducibility, computational throughput, operational convenience, and future workflow extensibility.

## 1.4 Thesis Organization

This dissertation is organized into six logically interconnected chapters, structured to systematically cover the transition from computational infrastructure modernization to detailed hydrodynamic applications:

Chapter 1 introduces the research background, delineates the operational limitations of legacy HPC CFD platforms, establishes the necessity of modern containerized virtualization, and outlines the research scope, objectives, and overall organization.

Chapter 2 presents the mathematical and physical foundations of the Truchas/DBM numerical model, followed by the technical execution of the framework modernization. This includes the implementation architecture of WSL2 and LXD, the container deployment strategy, and the modular refactoring of key legacy Fortran subroutines.

Chapter 3 describes the design and implementation of the automated workflow pipeline and the LLM-driven agent supervisor. It details the interaction between Python execution scripts, GUI parameter setup tools, runtime diagnostics, and AI-assisted simulation management.

Chapter 4 demonstrates the application of the modernized framework to a macro-scale coastal hazard case study: the landslide-generated tsunami at Guishan Island. This chapter provides detailed analyses of wave generation mechanisms, propagation characteristics, and coastal impact, accompanied by rigorous computational performance benchmarks comparing the WSL2/LXD container setup against legacy bare-metal execution.

Chapter 5 extends the physical validation to a micro-scale fluid-structure-soil interaction problem: local scour depth evolution and turbulent flow structures around the multi-pier foundation of the Guandu Bridge. It evaluates the model's capability in resolving dynamic bed boundaries and sediment transport under hydrodynamic forcing.

Chapter 6 summarizes the principal scientific conclusions and technical contributions of this research, acknowledges current technical limitations, and discusses future research perspectives regarding GPU acceleration, open-source community integration, and digital twin applications for marine infrastructure.
